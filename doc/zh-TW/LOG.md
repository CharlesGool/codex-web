## 限制

上游基線: `0dfdc10`

原因: fork 保留了上游 npm 和 Nix 包根及其提取然後修補工作流程.移動這些繼承的條目會改變包路徑並使上游更新變得複雜.產生`scratch/`提取輸出仍然被 Git 忽略, 並且僅由繼承的建置工作流程使用.

更新邊界: 此處僅保留記錄基線中存在的根條目.新的第一方文件使用標準項目目錄; 任何新繼承的上游條目都需要審查和準確的庫存更新.

文件和許可審查: 上游結帳聲明 MIT`package.json`但不包含完整的許可文本.提取的桌面捆綁包和 npm 依賴項通知尚未經過完全審核.看[Third-party notices](THIRD_PARTY_NOTICES.md).這限制了有關重新分發提取或捆綁的工件的主張.

|點擊時下載對話訊息中的本機存檔連結.|桌面文件開啟操作沒有這些文件的可用瀏覽器目標.|

|將部署移至`~/Desktop/apps/codex-web`, 節點位於該目錄內.|然後, 啟動器使用一種獨立的部署路徑; 先前的部署仍然需要回滾.|

|在全螢幕預覽工具列中使用文字標籤進行刪除.|Close 旁邊的第二個 X 在視覺上令人困惑; 文字按鈕保持了工具列的風格並使操作變得清晰.|
|為登入頁面提供一個居中的卡片, 其中包含帳戶和密碼欄位以及真正的可信任 IP 檢查.|參考佈局提高了層次結構; 次要操作檢查現有伺服器白名單並解釋拒絕.|
|將登入頁面保留為登出後的入口點, 包括受信任的 IP.|在登入頁面明確選擇可信任IP存取; 單獨的 IP 並不能建立會話.|

|僅將滾動更新提案保留為歷史設計.|與添加代理和重疊後端複雜性相比, 用戶更喜歡明確確認門.沒有實施代理或任務遷移.|
|從標題選單和側邊欄行選單在瀏覽器標籤中開啟本機聊天.|桌面新視窗 IPC 操作不會開啟可用的瀏覽器視窗.兩個選單現在都使用瀏覽器的`/thread/<id>`路線, 側邊欄行在 Codex 模式下公開其選單按鈕.遠端主機聊天被排除, 因為瀏覽器路由不會恢復其主機上下文.|
|在經過身份驗證的瀏覽器標籤中預覽從對話連結的本機檔案.|桌面檔案編輯器標籤可能無法在 Web 主機中呈現.預覽會讀取現有的經過驗證的下載端點, 顯示文字, 圖像或 PDF, 並提供下載.遠端主機連結保持其原始操作.|
|使用現有的 find-in-chat 指令將搜尋按鈕新增到對話標題.|客戶端已經有一個帶有匹配計數和上一個/下一個導航的查找欄; 標頭缺少可見的入口點.|
|將 Web 應用程式的大小調整為行動裝置和平板電腦上瀏覽器的視覺視窗.|繼承的`100vh`root 和 shell 的高度可能會超過動態瀏覽器列或螢幕鍵盤留下的區域.視覺視窗還報告其頂部偏移量, 該偏移量在鍵盤可見時可能會發生變化.|
|在此瀏覽器中將語音及一般 ChatGPT 聊天記錄標示為不可用.|目前透過 HTTP 提供的頁面無法存取麥克風, 桌面語音功能也不會自動移植; 本機 Codex app-server 不會列出一般 ChatGPT 帳號的聊天. 隱藏語音操作, 保留 Codex 對話記錄.|
|從側邊欄問號選單開啟本機更新紀錄頁面.|使用者希望查看此分支的更新記錄; 頁面讀取隨靜態資源提供的當前語言更新紀錄.|

## 變更紀錄

### 0.0.1(未發布; 作品更新於 2026-09-28)

#### 改變了

- 本機文件上下文功能表現在提供瀏覽器支援的文件操作.
- 側邊欄問號選單現在連結到 GitHub 上的這個分支; 僅桌面應用程式選單保持隱藏.對話搜尋欄位現在與現有選單的白色表面和微妙陰影相符.
- 寵物, 鍵盤快速鍵和電腦使用設定顯示不可用狀態; 側邊欄"說明"功能表不再提供 Chrome 擴充功能設定.計劃任務現在顯示特定部署的不可用狀態, 而不是損壞的雲端清單和任務建議. Pet 設定檔操作, pet 斜線命令, 捷徑說明項目, 應用程式捷徑綁定, 桌面應用程式選單和過時的預設檔案開啟目標設定在 Web UI 中隱藏或停用.
- 該專案保留了繼承的上游建置佈局, 同時將新的第一方結構和服務啟動器移至標準目錄中.

- 網頁中的語音操作已隱藏或標示為不可用; ChatGPT 聊天記錄區域說明此處無法同步網頁及手機的一般聊天. 側邊欄說明選單現可開啟本機更新紀錄頁面.
#### 固定的

- 本機網站資源卡開啟靜態瀏覽器預覽, 而不是呼叫不可用的應用程式內瀏覽器.
- 對話訊息中的本機存檔連結會下載引用的文件, 而不是呼叫不可用的桌面應用程式.
- 未發送圖像的全螢幕預覽現在包括將其從草稿中刪除的操作.
- 預覽刪除操作現在顯示文字而不是 X, 並且登入頁面使用重新設計的帳戶/密碼表單以及有效的可信任 IP 檢查.
- 聊天選單的新視窗操作會開啟一個瀏覽器選項卡, Codex 側邊欄聊天行會顯示相同的選單.
- 對話檔案連結會開啟帶有下載按鈕的瀏覽器預覽, 而不是無法呈現的標籤.
- 對話標題現在提供一個搜尋按鈕, 可開啟現有的查找欄.
- 現在, 當瀏覽器欄, 旋轉或鍵盤更改可用高度時, 行動裝置和平板電腦佈局將遵循可見視口.
