## مقدمة

تعمل هذه الشوكة على تشغيل واجهة Codex لسطح المكتب في المتصفح مع الاحتفاظ بـ Codex CLI والوصول إلى الملفات على الجهاز الذي تتحكم فيه. فهو يضيف مصادقة المتصفح، وإجراءات الملفات المحلية، ومعاينة ثابتة لموقع الويب، وإصلاحات لعناصر التحكم الموجودة على سطح المكتب فقط. يتم استخراج تطبيق سطح المكتب وتعديله باستخدام التصحيحات ذات الإصدار أثناء الإنشاء.

## المتطلبات

- الحد الأدنى: Node.js وnpm متوافقان مع`package.json`وGit وCodex CLI الذي تم تسجيل الدخول إليه وحزمة Codex لسطح المكتب المدعومة للاستخراج. يحتاج البناء إلى الوصول إلى الشبكة لجلب تلك الحزمة. يجب أن يكون المتصفح قادرًا على الوصول إلى المضيف والمنفذ المختارين.
- موصى به: التشغيل خلف HTTPS أو نفق مشفر. استخدم حساب مضيف مخصصًا واحتفظ بالخدمة على شبكة موثوقة. يمكن أن تعمل واجهة المستخدم المجمعة وواجهة برمجة التطبيقات المصادق عليها مع أذونات الملفات والأوامر الخاصة بهذا الحساب.

## التثبيت

### تثبيت سريع

من الخروج مع حزمة سطح المكتب المعدة والتبعيات المثبتة، قم بتشغيل`npm run prepare && ./deploy/start.sh`. الخادم يستمع`127.0.0.1:8214`بشكل افتراضي.

### تثبيت عادي

1. تثبيت Node.js، وnpm، وGit، وCodex CLI؛ تسجيل الدخول مع`codex login --device-auth`.
2. يجري`npm ci`، ثم`npm run prepare`. يستخرج البناء حزمة سطح المكتب، وينطبق`patches/*.patch`، يبني المتصفح والخادم، وينشئ أصول الويب المضغوطة.
3. لنشر الشبكة، قم بإنشاء بيانات اعتماد باستخدام`node scripts/set-auth-password.mjs USERNAME`; تسجيل كلمة المرور التي تم إنشاؤها بشكل آمن.
4. يجري`./deploy/start.sh --host HOST --port PORT`، ثم افتح عنوان URL المطابق. يرى[Design](doc/DESIGN.md)لتخطيط النشر والحدود.

## إرشادات

- تستخدم واجهة مستخدم المتصفح Codex CLI الذي تم تسجيل الدخول إليه على المضيف. يمكن تنزيل الملفات المحلية أو فتحها في خدمة متصفح الملفات المنفصلة إذا تم تكوينها.
- يفتح مورد موقع الويب معاينة ثابتة للعرض فقط. ولا يبدأ الواجهة الخلفية لموقع الويب هذا.
- يمكن إزالة الصورة التي تنتظر الإرسال إما من الصورة المصغرة أو من المعاينة بملء الشاشة. تؤدي إزالته إلى منع تضمينه في المسودة.
- لا يزامن هذا الموقع محادثات ChatGPT العادية من الويب أو الهاتف. عناصر التحكم الصوتي غير متاحة هنا، وتوضح صفحة إعدادات الصوت ذلك. تفتح قائمة علامة الاستفهام سجل تغييرات هذا المشروع. تستخدم صفحة سجل التغييرات اللغة المحددة في Codex Web.
- `CODEX_CLI_PATH`يختار CLI.`CODEX_WEB_NODE_BIN_DIR`و`CODEX_WEB_GIT_BIN_DIR`حدد أدلة أدوات وقت التشغيل عندما تكون بالخارج`PATH`. `CODEX_WEB_AUTH_FILE`و`CODEX_WEB_TRUSTED_IPS_FILE`حدد ملفات المصادقة. انظر[previous upstream-oriented README](third_party/codex-web/README.previous.md)لتدوير بيانات الاعتماد وأوامر IP الموثوق بها.
- قد تكون هناك حاجة إلى تحديث ثابت بعد استبدال أصل الويب دون تغيير اسم الملف الخاص به لأنه يمكن تخزين الأصول ذات الإصدار مؤقتًا لفترة وجيزة.

## الترقية

1. نسخ احتياطي`~/.config/codex-web/auth.json`و`~/.config/codex-web/trusted-ips.json`وتسجيل الإصدار قيد التشغيل ومسار النشر.
2. اسحب المراجعة المطلوبة في عملية دفع منفصلة وقم بتشغيلها`npm ci && npm run prepare`. قم بمراجعة أي تصحيح فاشل مقابل إصدار حزمة سطح المكتب قبل النشر.
3. انسخ الملفات المعدة إلى دليل النشر. لا يتطلب استبدال الأصول الثابتة وحده إعادة تشغيل الخادم؛ تغييرات الخادم تفعل. تؤدي عملية إعادة التشغيل التي يبدأها المشغل إلى مقاطعة المحادثات والمهام النشطة، لذا احصل على تأكيد صريح من المستخدم لعملية إعادة التشغيل المحددة هذه بعد التحضير والفحوصات.
4. افتح صفحة تسجيل الدخول وتحقق من تسجيل الدخول وواجهة مستخدم المتصفح والميزة التي تم تغييرها. احتفظ بالنشر السابق حتى تمر عمليات التحقق هذه. يرى[Upgrading](UPGRADING.md)لسير عمل التحديث الموروث.

## إلغاء التثبيت

- سريع: قم بإيقاف الخدمة وإزالة دليل الدفع أو النشر للتطبيق. احتفظ بملفات التكوين إذا كنت تتوقع إعادة التثبيت.
- كامل: قم أيضًا بإزالة خدمة مستخدم systemd،`~/.config/codex-web/auth.json`, `~/.config/codex-web/trusted-ips.json`وأي بيانات وقت تشغيل مخزنة بشكل منفصل أو بيانات متصفح الملفات تمتلكها. قم بمراجعة هذه المسارات قبل الحذف إذا تمت مشاركتها بواسطة عملية نشر أخرى.
